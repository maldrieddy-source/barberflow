# BarberFlow

Protótipo de uma aplicação web para agendamento de serviços de barbearia. A interface demonstra o fluxo de navegação, cadastro, escolha de serviços e agendamento.

## Requisitos

- Node.js 18 ou superior
- npm

## Executar localmente

```bash
npm install
npm start
```

Depois, acesse http://localhost:3000.

O arquivo `.env.example` mostra as variáveis opcionais usadas pelo servidor. Copie-o para `.env` e configure sua própria chave de API se quiser testar a integração. O arquivo `.env` não deve ser enviado ao Git.
